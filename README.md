# ApplyPilot
### Understand the Market. Build Your Skills. Find Your Opportunity.

## Overview

ApplyPilot is an AI-powered career intelligence and job application assistance platform that helps candidates understand employment market requirements, identify skill gaps, improve resumes and discover relevant job opportunities.

Instead of functioning as just another job portal, ApplyPilot connects candidate capabilities with real-world hiring demand and supports the complete job-seeking lifecycle.

## Project Objectives

- Analyse job-market trends, in-demand skills, technologies and experience requirements.
- Build structured candidate profiles from uploaded resumes.
- Identify skill gaps between candidate capabilities and market requirements.
- Generate personalised career improvement and learning recommendations.
- Improve and tailor resumes and cover letters using AI.
- Discover and recommend relevant job opportunities.
- Calculate candidate-job compatibility scores.
- Assist with application preparation and track application progress.

## Architecture

JobZilla follows a modular application architecture:

- **Frontend:** Next.js and TypeScript.
- **Backend:** Python and FastAPI.
- **Database:** PostgreSQL with optional pgvector support.
- **AI:** Hosted LLM inference through a free-tier API.
- **Background processing:** Celery and Redis.
- **Document processing:** PyMuPDF and python-docx.
- **Containerisation:** Docker and Docker Compose.
- **CI/CD:** GitHub Actions.
- **Monitoring:** Prometheus and Grafana (later phase).


## Core Modules

1. Candidate Profile Management
2. Resume Parsing and AI Resume Studio
3. Job Discovery and Data Collection
4. Career Intelligence and Market Analysis
5. Candidate Skill-Gap Analysis
6. Intelligent Job Matching
7. Application Assistance and Tracking


## Project Outcome

A working end-to-end platform demonstrating full-stack engineering, AI integration, data analytics, Docker-based deployment, CI/CD and DevOps practices.
